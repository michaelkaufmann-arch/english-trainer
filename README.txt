English Trainer A1–B2

Neue Version: mehrere englische Bedeutungen pro deutscher Lernkarte, CEFR-Stufen A1–B2, kumulativer Niveaufilter, Aussprache und Spaced Repetition.

Die App lädt beim ersten Start die Deutsch-Englisch-Wortliste und eine öffentliche CEFR-Wortliste. Die CEFR-Zuordnung ist wortbezogen; bei mehrdeutigen Wörtern können mehrere Niveaus vorkommen.
